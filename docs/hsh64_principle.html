检索架构
HSH-64 将高维连续嵌入压缩为单个 64 位整数，通过 POPCNT 指令实现极速 Hamming 距离计算。核心设计将 64 位划分为 feat(4)、sim(52)、abs(8) 三个字段，分别负责粗粒度分类、语义相似度和簇内消歧。

结构化 64 位编码

feat(4) + sim(52) + abs(8) = 一个 u64

feat（4 位）· 词性/粗分类
sim（52 位）· 语义相似度
abs（8 位）· 簇内完美哈希
$$ c = \underbrace{(f_3 f_2 f_1 f_0)}_{\text{feat}: 4} \;\|\; \underbrace{(s_{51} \cdots s_1 s_0)}_{\text{sim}: 52} \;\|\; \underbrace{(a_7 \cdots a_1 a_0)}_{\text{abs}: 8} $$

feat 字段

  • 4 位，16 个粗粒度类别
  • 对应词性、语义大类等先验
  • 可作为硬过滤条件

sim 字段

  • 52 位，核心语义相似信号
  • $2^{52} \approx 4.5 \times 10^{15}$ 种状态
  • 由 Deep Hash MLP 学习得到

abs 字段

  • 8 位，256 个唯一标识
  • 簇内完美哈希，用于消歧
  • 作为平手打破者而非语义信号

Hamming 距离

  • 两个编码一次 XOR
  • CPU POPCNT 单指令计数
  • 距离越小，语义越接近
$$ d_H(c, c') = \operatorname{popcnt}(c \oplus c') $$
Hamming 距离计算示例：XOR + POPCNT

阶段 2：STE 离散精调

符号量化 + 直通估计器，让二值码可训练

连续 Logit

  • $\mathbf{u} \in \mathbb{R}^{52}$
  • 前向传播使用
  • 可微分
→

Sign 量化

  • $\mathbf{b} = \operatorname{sign}(\mathbf{u})$
  • $\mathbf{b} \in \{-1,+1\}^{52}$
  • 用于 Hamming 距离
→

STE 回传

  • 前向：硬量化
  • 反向：梯度直传
  • $\frac{\partial \mathbf{b}}{\partial \mathbf{u}} \approx \mathbf{I}$
$$ \operatorname{sign}(u) = \begin{cases} +1, & u \ge 0 \\ -1, & u < 0 \end{cases} $$
# 前向传播 b = sign(u) # 硬量化，输出 ±1 loss = recall_loss(b, targets) # 反向传播（STE） # sign(u) 的导数在原点外为 0，但 STE 把梯度直接传回 u grad_u = grad_b.clone() # ∂b/∂u ≈ I
sign 函数几乎处处梯度为零，无法直接反向传播。STE（Straight-Through Estimator）在前向传播时使用硬量化，在反向传播时把梯度原样传回量化前的 logit，实现端到端的离散码学习。

阶段 3：贪心后处理

直接在离散码上优化 Recall@K

评估当前码

  • 计算 Hamming 距离
  • 得到 Recall@K
  • 记录基准 R₀
→

尝试翻转比特

  • 遍历候选位 j
  • 翻转 b_j → b'_j
  • 计算 ΔRecall
→

保留提升

  • 若 ΔRecall > 0 接受翻转
  • 多轮迭代直到收敛
  • 避免陷入局部最优
for iter in range(max_iters): for i in range(N): best_delta = 0 best_bit = None for j in range(52): code_i.flip(j) delta = compute_recall_delta(code_i) if delta > best_delta: best_delta, best_bit = delta, j code_i.flip(j) # 恢复，尝试下一位 if best_bit is not None: code_i.flip(best_bit)
后处理跳出梯度近似，直接以 Recall 为目标函数进行贪心比特翻转。这是从约 0.69 提升到 0.74 Recall@10 的关键步骤，通常只需 5–10 轮迭代即可收敛。

MIH 多索引哈希

将 52 位 sim 码切分为 13 段，构建倒排索引

52 位 sim 码 = 13 段 × 4 位
每段映射到 $2^4 = 16$ 条倒排索引
$$ \text{segment}_s = \text{sim}[4s : 4s+4], \quad s = 0, \dots, 12 $$
# 构建 MIH 索引 for s in range(13): # 13 段 for i, code in enumerate(codes): seg_val = extract_bits(code, s*4, 4) index[s][seg_val].append(i)
MIH 将长二进制码拆成多个短子串，为每个子串建倒排索引。查询时只需枚举每段在 Hamming 半径内的可能取值，再合并候选列表，检索复杂度从线性降至亚线性。

非对称距离评分

查询端用原始 logit，文档端用二值码

对称距离

查询和文档都量化成二值码后比较 Hamming 距离。

$d_H(q, d) = \operatorname{popcnt}(q \oplus d)$

存在量化损失。

非对称距离

查询端保留连续 logit，文档端使用二值码。

$s(q, d) = \sum_{j} \operatorname{sign}(u_j) \cdot u_j$

减少查询端量化误差。

$$ s_{\text{asym}}(q, i) = \mathbf{u}_q^\top \mathbf{b}_i = \sum_{j=1}^{52} u_{q,j} \cdot b_{i,j} $$
非对称评分让在线查询保留更多连续信息，同时文档端仍享受二值存储的高效率。这是提升检索精度的另一项关键技术。
